# README screenshots

These are actual screen recordings from a Retroid Pocket 6 running ROCKNIX,
captured on 2026-09-28 for the Desktop Mode motion reel. The gallery uses
unaltered 1280×720 frames exported as optimized PNGs; no interface elements were
added or simulated. Click a README image to view it at full size.

| Image | Recorded feature |
| --- | --- |
| [apps.png](apps.png) | Apps launcher with Files selected through the installed D-pad mapping |
| [keyboard.png](keyboard.png) | New Desktop-only four-row typing layout filtering the launcher |
| [settings.png](settings.png) | Custom audio, network and layout menu with Firefox PiP still visible |
| [vulkan-pip.png](vulkan-pip.png) | Turnip Vulkan cube and Firefox PiP displayed together |

The keyboard capture uses the installed two-page keyboard introduced in commit
`479b82f`, included in development revision `929c473`. Earlier captures in this
gallery predate that keyboard update. Recordings demonstrate the visible UI;
they are not performance benchmarks. Input was sent through the installed
controller key mappings and pointer targets, rather than filmed physical presses.

licensed under [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/).
It appears within the actual browser PiP window, scaled by Firefox and captured
as part of the desktop. See the film's [license and attribution information](https://peach.blender.org/about/).

Screenshots are documentation assets and are not installed on the device.
When reading the README from an extracted bundle, view the
[GitHub gallery](https://github.com/kapdon/rocknix-desktop/tree/dev#desktop-preview)
for the images.
