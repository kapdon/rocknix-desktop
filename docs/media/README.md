# Desktop screenshots

ROCKNIX Desktop on the Retroid Pocket 6. These screenshots show the Apps menu,
on-screen keyboard and settings at 1.0× display scaling.

| Image | Visible feature |
| --- | --- |
| [apps.png](apps.png) | Apps with Firefox, Files and Foot favorites |
| [keyboard.png](keyboard.png) | Four-row keyboard filtering Apps above it |
| [settings.png](settings.png) | Audio, Network, Display and window-layout options |
| [display.png](display.png) | Scaling and resolution/refresh-rate controls |

Files shows the five shared folders behind the menus. See the
[desktop guide](../desktop-guide.md) for controls and window behavior.

For the gallery when viewing an extracted bundle, open the
[GitHub README](https://github.com/kapdon/rocknix-desktop/tree/dev#desktop-preview).
